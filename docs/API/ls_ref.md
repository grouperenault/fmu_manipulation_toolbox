# FMI-LS-REF

Validation of the results of an FMU from the reference material of FMI-LS-REF (see
[FMU Checker](../user-guide/fmutool/checker.md#validation-of-the-results-fmi-ls-ref)): the experiment files, the time
series of their stimuli and references, and the replay of an experiment with the runtime of the FMU Container.
