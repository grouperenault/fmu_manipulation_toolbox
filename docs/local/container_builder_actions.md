# Plan: actions of the Container Builder (Open, Save as)

**Created**: 1 November 2026 — **Status**: in progress

The button bar of the Container Builder has grown with the formats: **Load FMU Container**, **Import**, **Export as
JSON**, **Export as SSP**, **Save as FMU Container**, **Exit**, next to **Configuration**. Five of them open or write an
assembly in some format; the choice of the button is the choice of the format. The goal of this plan is two actions,
**Open…** and **Save as…**, the format following the file.

---

## 1. Current state

- `gui/fmucontainer/__main__.py`: one `QPushButton` per action (`_load_button`, `_import_button`, `_export_button`,
  `_export_ssp_button`, `_save_button`, `_exit_button`), and **Configuration**, a button with a menu.
- `MainWindow.open_file(path)` already dispatches on the extension (`.fmu`: load; `.json`, `.csv`, `.ssp`: import):
  used by `fmucontainer-gui <file>`.
- Writers: `save_as_json`, `save_as_ssp`, `save_as_fmu(path, fmi_version, datalog)` (`assembly_io.py`); the FMU save
  asks for the FMI version and the datalog option.
- Dialogs: `LastDirectory.get_save_file_name` / open dialog, one filter per button.
- Tests: `tests/gui/test_gui.py`, `tests/gui/test_fmucontainer_ssp_export.py` use the buttons or their handlers.
- Documentation: `docs/user-guide/fmucontainer/gui-usage.md` (Actions table, steps of the workflow), screenshots
  generated by `tools/screenshots.py`.

---

## 2. Decisions

| # | Question | Decision |
|---|---|---|
| B1 | Grouping | **Open…** (a `.fmu` container is loaded, a `.json`, `.csv` or `.ssp` file imported, after the extension) and **Save as…** (FMU Container, SSP or JSON, after the filter or the extension chosen in the dialog), plus **Exit** and **Configuration** (1 November 2026). |
| B2 | Default format of Save as… | **FMU Container**, then the format chosen last in the session; the FMI version and the datalog stay in the Configuration menu (1 November 2026). |
| B3 | Open… on unsaved changes | **Asked**, with the dialog of Exit (go on and lose the changes, or cancel); Load and Import did not ask (1 November 2026). |
| B4 | Shortcuts | **Ctrl+O** opens Open…, **Ctrl+S** opens Save as… (the dialog always shown); no quick save overwriting the last file (1 November 2026). |
| B5 | CSV in Save as… | **No**: FMU Container, SSP and JSON; CSV stays readable by Open… (1 November 2026). |

---

## 3. Changes

- `gui/fmucontainer/__main__.py`: two buttons instead of five, their handlers; the old handlers removed.
- `assembly_io.py`: unchanged writers; a `save_as(path, format)` dispatch.
- The MCP bridge (`mcp_bridge.py`) calls the writers directly: unchanged.
- Tests of the buttons; screenshots and documentation.

---

## 4. Steps

1. **Open…** (B3): one dialog with every format, dispatch through `open_file`. GUI tests.
   Commit message: `Container builder: one Open action for containers and assembly files`
   **Done** (1 November 2026): **Open…** (Ctrl+O), every format in the first filter, dispatch through `open_file`.
   The dialog of Exit is now `UnsavedChangesWindowMixin._confirm_discard_changes(text)`, shared by Exit and Open…
   (asked before the file dialog). The old buttons stay until step 3. Tests: `tests/gui/test_fmucontainer_actions.py`.
2. **Save as…** (B2, B4, B5): format after the filter or the extension, FMU options. GUI tests.
   Commit message: `Container builder: one Save as action for every format`
   **Done** (1 November 2026): **Save as…** (Ctrl+S): filters FMU Container, SSP, JSON; the extension typed decides,
   otherwise the filter chosen, its extension appended (`MainWindow.save_target`); the last format of the session
   preselected (`LastDirectory.get_save_file_name_and_filter`). The SSP save now clears the unsaved changes, as the
   JSON and FMU saves.
3. **Old buttons removed**, tests updated.
   Commit message: `Container builder: remove the per-format buttons`
   **Done** (1 November 2026): Load FMU Container, Import, Export as JSON, Export as SSP, Save as FMU Container and
   their handlers removed; `load_file`, `import_file`, `open_file` kept (Open…, command line). Button bar:
   Configuration | Open… · Exit · Save as…. Tests updated (`test_gui.py`, `test_fmucontainer_ssp_export.py`).
4. **User documentation** (`gui-usage.md`: actions, workflow; screenshots regenerated with `tools/screenshots.py`)
   and CHANGELOG.
   Commit message: `Document the Open and Save as actions of the container builder`
